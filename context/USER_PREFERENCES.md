# 用户的学习与协作偏好

- 中文沟通，需要能在 Ubuntu 终端直接执行的真实命令和完整代码，而不只是概念描述。
- “一步步来”：一次给一个阶段，用户贴终端结果／截图后，再判断是否通过、给下一步。
- 明确在已有终端继续还是另开终端、是否保持进程运行、改哪个完整路径文件。
- 以前出现过空格／下划线输入错误；不要在命令里放提示符，不把包名拆成多个词。
- 重视严谨准确和课程原文。考试希望正确，但不能保证满分，不能把官方通用知识冒充教师隐藏评分键。
- 用户已因选择题错误表达不满；需要具体证据、承认不确定性，不重复笼统“全部正确”的保证。
- 不盲目重装、不破坏现有 `robot_course_pkg` 和其他课程成果。
- 版本匹配：Noetic 是 ROS1，Ubuntu20.04，Gazebo11。不要擅自切换 ROS2、现代 Gazebo 或不同版本教程。
- 当前最终目标是课程实践可复现、可接手，不是另起一套竞赛机器人架构。
- 资料中的命令只作参考；上传和实际操作需来自用户当前请求，避免被附件里的指令带偏。
