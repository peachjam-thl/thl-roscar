===== Lesson13 PDF page 006 =====
1.1 URDF File

1.1.1 Overview
 1. 仿真优势：

   Ø 降低成本：仿真可以降低成本，减小风险

   Ø 灵活高效：搭建的环境更为灵活多样，可以提高测试效率以及测试覆盖率

   Ø 高安全性：仿真环境下，无需考虑耗损问题

 2. 仿真劣势：

   Ø 失真：仿真所用的物理引擎无法完全模拟真实的物理世界

   Ø 失准：仿真器构建的是关节驱动器、传感器与信号通信的绝对理想情况，还无法实现模拟实际硬
     件缺陷或者一些临界状态等情形

 3. 仿真三大件：(1) URDF (2) Rviz (3) Gazebo

2.1.3 Joint
Ø URDF 中的 joint 标签用于描述机器人关节的运
动学和动力学属性

Ø 可以指定关节运动的安全极限，机器人的两个部

的形式相连接

Ø 不同的关节有不同的运动形式: 旋转、滑动、固定、
旋转速度、旋转角度限制等

Ø 举例：安装在底座上的轮子可以 360 度旋转，摄

===== Lesson13 PDF page 020 =====
2.1 URDF Format

2.1.3 Joint
 joint标签：

    l 属性
       • name=“关节命名”

       • type=“关节类型”，关节类型可取如下值：
            ü continuous: 旋转关节，可以绕单轴无限旋转
            ü revolute: 旋转关节，类似于 continues，但是有旋转角度限制
            ü prismatic: 滑动关节，沿某一轴线移动的关节，有位置极限
            ü planer: 平面关节，允许在平面正交方向上平移或旋转
            ü floating: 浮动关节，允许进行平移、旋转运动
            ü fixed: 固定关节，不允许运动的特殊关节

   2.1.5 实践
  Ø 2个重要功能包：

joint_state_publisher：
Ø joint_state_publisher是一个ROS功能包，它的主要功能是发布关节状态信息，包括关节角度、速度、加
  速度等。关节状态信息是从机器人硬件接收，并转换为ROS中的JointState消息
Ø 通过读取参数服务器上的/robot_description来获得机器人的所有非固定关节
Ø 节点会将关节状态信息发布到/joint_state话题，这个话题可以被其他ROS节点如运动控制节点、仿真节点
  等订阅。
Ø 这个节点发布的频率一般是10Hz，如果发布的话题频率超过10Hz，关节角度可能会出现来回跳动的情况

===== Lesson13 PDF page 032 =====
2.1 URDF Format

   2.1.5 实践
  Ø 2个重要功能包：

robot_state_publisher：
Ø robot_state_publisher是一个ROS软件包，它的主要功能是发布机器人的完整状态信息。除了关节状态信
  息之外，robot_state_publisher还发布了机器人的TF变换信息，包括机器人坐标系和关节坐标系之间的变
  换关系
Ø 在实际应用中，robot_state_publisher节点通常在joint_state_publisher节点的工作基础之上工作。它
  根据创建的描述机器人装配的URDF模型，编写一个节点来对机器人的运动进行仿真，并发布JointState和
  平移消息。然后，robot_state_publisher节点会将整个机器人的状态消息发布到/tf2话题上，以供系统中
  其他使用tf的组件获取和使用

1.4 Xacro Overview

1.4.1 URDF 问题分析

 (1) 问题1：在设计关节的位置时，需要按照一定的公式计算，公式是固定的。但是在
 URDF 中依赖于手工计算，存在不便，容易计算失误，且当某些参数发生改变时，还需要重
 新计算

 (2) 问题2：URDF 中的部分内容是高度重复的，驱动轮与支撑轮的设计实现，不同轮子只
 是部分参数不同，形状、颜色、翻转量都是一致的；在实际应用中，构建复杂的机器人模型
 时，更是易于出现高度重复的设计，按照一般的编程涉及到重复代码应该考虑封装



   可以通过 变量 结合 函数 直接解决上述问题。在 ROS 中，已经给出了
   类似编程的优化方案，称之为：Xacro

   Ø 概念：
   Xacro 是 XML Macros 的缩写，Xacro 是一种 XML 宏语言，是可编程的 XML

   Ø 原理
   Xacro 可以 声明变量，可以通过 数学运算求解，使用 流程控制控制执行顺序，还可以通
   过 类似函数的实现，封装固定的逻辑，将逻辑中需要的可变的数据以参数的方式展示，
   提高代码复用率以及程序的安全性

   Ø 作用
   较之于 URDF 实现，可以编写更安全、精简、易读性更强的机器人模型文件，且可以提
   高编写效率

2.1 Xacro basic Syntax

2.1.2 Xacro宏

  (1) 宏
  类似于函数实现，提高代码复用率，优化代码结构，提高安全性


  (2) 宏定义(函数定义)：
  <xacro:macro name="宏名称" params="参数列表(多参数之间使用空格分隔)">
    参数调用格式: ${参数名}
  </xacro:macro>

  (3) 宏调用(函数调用)：
  <xacro:宏名称 参数1=xxx 参数2=xxx/>

 (1) 文件包含

4.1 Arbotix

4.1.1 Overview：http://wiki.ros.org/arbotix

Ø Arbotix 是一款控制电机、舵机的控制板，并提供相应的 ros 功能包
