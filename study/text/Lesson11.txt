1.1 rqt

1.1.1 Overview
Ø 在 ROS 中，rqt 工具箱可以以图形化操作代替命令行操作，操作过程更加直观和便利，有效提
  高操作效率，提升用户体验

Ø 概念
   l rqt 是 ROS 基于 QT 框架，针对机器人开发的一系列可视化工具集合

Ø 作用
   l rqt 可以方便的实现 ROS 可视化调试，并且在同一窗口中打开多个部件，提高开发效率，
     优化用户体验

Ø 组成
   l rqt 工具箱组成有三大部分：
       1. rqt——核心实现，开发人员无需关注
       2. rqt_common_plugins——rqt 中常用的工具套件
       3. rqt_robot_plugins——运行中和机器人交互的插件(比如：rviz)

1.1.1 Overview
Ø TF(TransForm Frame)官方参考文档：http://wiki.ros.org/tf2

Ø tf is a package that lets the user keep track of multiple coordinate frames over time. tf
  maintains the relationship between coordinate frames in a tree structure buffered in
  time, and lets the user transform points, vectors, etc between any two coordinate
  frames at any desired point in time.

Ø tf2 is the second generation of the transform library, which lets the user keep track of
  multiple coordinate frames over time. tf2 maintains the relationship between
  coordinate frames in a tree structure buffered in time, and lets the user transform
  points, vectors, etc between any two coordinate frames at any desired point in time.
