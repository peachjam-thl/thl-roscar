===== Lesson15 PDF page 026 =====
3.1 Navigation

    3.1.3 Navigation structure

1 全局地图

Ø   SLAM(simultaneous localization and mapping)，即时定位与地图构建。SLAM问题可以描述为: 机器
    人在未知环境中从一个未知位置开始移动，在移动过程中根据位置估计和地图进行自身定位，同时在自身定位
    的基础上建造增量式地图，以绘制出外部环境的完全地图

Ø 在 ROS 中，常用的 SLAM 包括 gmapping、hector_slam、cartographer、rgbdslam、ORB_SLAM等


Ø SLAM建图 ，机器人需具备感知外界环境的能力，尤其是获取周围环境深度信息的能力。感知的实现需要依
    赖于传感器，比如: 激光雷达、摄像头、RGB-D摄像头等


Ø SLAM 生成的地图需要被保存以待后续使用，在 ROS 中保存地图的功能包是 map_server

===== Lesson15 PDF page 027 =====
3.1 Navigation

  3.1.3 Navigation structure

2 自身定位

Ø 导航过程中，机器人需要实时确定当前自身的位置。如果在室外，可以使用GPS辅助定位；在室内、隧道、
 地下或一些屏蔽 GPS 信号的区域，需要使用具备自身定位功能的功能包，例如：AMCL

Ø AMCL(adaptive MonteCarlo Localization)自适应的蒙特卡洛定位，是用于2D移动机器人的概率定位
 系统。它实现了自适应（或KLD采样）蒙特卡洛定位方法，该方法使用粒子过滤器根据已知地图跟踪机器
 人的姿态

===== Lesson15 PDF page 028 =====
3.1 Navigation

 3.1.3 Navigation structure
3 路径规划

Ø 导航过程中，机器人需要根据目标位置计算最优路径，此过程称为全局路径规划。在运动过程中，机器人
 需要根据障碍物动态调整运动路线，此过程就称为局部路径规划


Ø 在 ROS 中提供了 move_base 功能包来实现路径规则，该功能包主要由两大规划器组成

  Ø 1 全局路径规划(gloable_planner)
     根据给定的目标点和全局地图实现总体的路径规划，使用 A* 或 Dijkstra 算法进行全局路径规划，
  计算最优路线，作为全局路线


  Ø 2 局部路径规划(local_planner)
     局部路径规划的作用就是使用相应算法(Dynamic Window Approaches，DWA) 等来实现障碍物
  的规避，并选取当前最优路径以尽量符合全局最优路径

5. 环境感知

Ø 感知周围环境信息，比如: 摄像头、激光雷达、编码器等

Ø 摄像头、激光雷达可以用于感知外界环境的深度信息，编码器可以感知电机的转速信息，通过获取
  速度信息并生成里程计信息

在导航功能包集中，环境感知是重要模块，它为其他模块提供了支持，包括 SLAM、AMCL、
move_base 都需要依赖于环境感知

3.1 Navigation

 3.1.4 Odom
定位实现方式有两种：

 1 通过里程计定位：实时收集机器人的速度
信息，计算并发布机器人坐标系与父级参考系
的相对关系

 2 通过传感器定位：通过传感器收集外界环
境信息，通过匹配计算并发布机器人坐标系与
父级参考系的相对关系

===== Lesson15 PDF page 033 =====
3.1 Navigation

 3.1.4 Odom
两种定位方式优缺点：

1 里程计定位

  优点：里程计定位信息是连续的，没有离
散的跳跃
  缺点：里程计存在累计误差，不利于长距
离或长期定位

2 传感器定位
 优点：比里程计定位更精准
 缺点：传感器定位会出现跳变的情况，在标
志物较少的环境下，其定位精度会大打折扣

两种定位方式优缺点互补，应用时一般二者结
合使用

===== Lesson15 PDF page 034 =====
3.1 Navigation

3.1.4 Odom


 Ø 上述两种定位实现中，机器人坐标系一般使用机器人模型中的根坐标系(root_link)

 Ø 里程计定位时，父级坐标系一般称之为 odom

 Ø 如果通过传感器定位，父级参考系一般称之为 map

 Ø 当二者结合使用时，map 和 odom 都是机器人模型根坐标系的父级，一般会将转换

   关系设置为: map -> doom -> base_link 或 root_link
