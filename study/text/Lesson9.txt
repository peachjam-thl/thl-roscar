C++ example-基于 ROS 编程
2.1 ROS Programming

2.1.1 Overview
Ø ROS 编程是指通过使用 ROS 提供的一些内置函数来编写 ROS 应用程序

Ø ROS编译系统

  l ROS 有一套自己的用于编译 ROS 程序包的编译系统，该系统名称是 catkin
    (http://wiki.ros.org/catkin)

  l catkin 是由 CMake 编译系统和 Python 脚本定制的一套特殊的编译系统，以解决 ROS 程序
    包复杂的编译过程
 2.1 ROS Programming

 2.1.1 Overview
Ø ROS catkin 工作空间

   l src：存储新创建的功能包或者从远程代码库复制下来的功能。ROS功能包只有在 src 文件夹中才
     可以被创建、编译和执行


   l build：执行 catkin_make 命令时，catkin 工具会在 build 文件夹中创建一些中间编译文件和中
     间缓冲文件。这些缓冲文件可以避免在执行 catkin_make 命令时重新编译所有功能包


   l devel：执行 catkin_make 命令时，如果编译成功，创建的可执行文件存储在 devel 文件夹中，
     该文件夹中还有一些脚本，可以将该工作空间添加到 ROS 的系统环境变量中
 2.1 ROS Programming

 2.1.2 使用ROS客户端库
Ø ROS客户端库是一系列实现了 ROS 概念所对应功能的代码

Ø 在编写 ROS 程序时，在代码中包含这些库函数便可以实现一个 ROS 节点

Ø 以下是主要的 ROS 客户端库：

  l roscpp：C++ 的 ROS 客户端库，被广泛用于 ROS 应用开发

  l rospy：Python 的 ROS 客户端库，其优点是语法简单，节省开发时间，但执行效率比 roscpp 低

  l roslisp：Lisp 语言的 ROS 客户端库

  l 其他客户端库：rosjava、rosnodejs、roslua

 2.1.2 使用ROS客户端库
