# 机器人建模及仿真实践提交材料

ROS课程实践｜2026年10月17日

## 材料清单

- `01_实践报告/`：六章实践报告 DOCX、PDF，以及可检索的 Markdown 正文。
- `02_ROS工程代码/`：独立 catkin 源码、运行说明、上游许可证、用户回传日志和验证记录。
- `03_关键截图/`：5张用户提供的四轮版真实 PNG，保持原始像素、比例和文件内容，仅规范文件名。
- `04_演示视频/`：按用户最新要求不处理录屏，未生成 MP4；若老师最终仍要求视频，需要另行补入真实视频。

当前成果是四轮四驱差速运动、关节状态与TF、激光扫描、Gazebo/RViz可视化；不包含四轮版深度相机恢复、SLAM、自主导航或自动避障。

## 先看运行说明

详见 `02_ROS工程代码/README.md`。请在独立工作空间测试提交副本，不覆盖原 `/home/thl/catkin_ws`。

原始阶段代码已有用户Ubuntu运行日志；整理后的源码在Windows通过Xacro展开、XML解析、Python 3.8语法、12项插件源码测试和文件一致性检查。没有在当前Windows环境进行Gazebo运行，也没有声称新副本已在干净Ubuntu完成端到端复测。

报告中的A/B结果是单次测试观测，不是多次统计结论；静态截图不单独证明运动轨迹，运动和时间戳结论由日志支持。
